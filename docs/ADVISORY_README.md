# 자문자 안내 — 경기도 데이터·후보 결과 자문 (자료 신뢰성·현실성 검토)

**이 화면은 연구 결과를 최종 확정하기 위한 화면이 아니라, 현재 경기도 자료와 그 자료로 만든 후보 결과가 실제 지역 현황을 얼마나 잘 반영하는지 전문가께 검토받기 위한 자문용 화면입니다.** 로그인·설치가 필요 없고, 일반 브라우저로 링크를 열면 됩니다.

- 최종 사업 가능성, 법적 인허가 가능성, 실제 계통 접속 가능 여부를 판단하는 화면이 아닙니다.
- 이번 자문에서 검토받는 것은 자료의 정확성·현실성·신뢰성·완전성·최신성입니다.
- 21m 묶음 기준·후보 비교 방식·가중치 같은 분석 방법의 타당성은 별도 자문에서 다룹니다.
- 실제 현장을 잘 아시는 지역이 있다면 후보 번호와 함께 알려 주십시오.
- 판단하기 어려운 항목은 "판단 어려움"으로 답하시거나 비워 두셔도 됩니다.
- **화면에 없는 요소가 중요하더라도 그것이 곧 현재 분석이 잘못되었다는 의미는 아닙니다. 현재 결과를 실제 검토에 활용하기 위해 추가로 필요한 자료나 확인해야 할 사항으로 의견을 남겨 주세요.**
- 의견은 서버로 자동 전송되지 않고 지금 쓰시는 브라우저에만 저장됩니다.

## 자료를 읽을 때 주의할 점

- **분석 조건** — 영농형태양광 특별법 시행 후, 농업진흥구역에 영농형 태양광을 설치할 수 있게 되는 경우(농업보호구역 제외)입니다. 후보 표시는 법적 사업 가능 여부 또는 인허가 가능 여부를 판단한 결과가 아닙니다.
- **후보 공간** — 현재 연구의 분석 조건을 통과한 법인·국공유 농지 필지를 21m 이내로 이어 묶은 검토 단위입니다. 면적 하한을 두지 않으므로 필지 한 개짜리 작은 공간도 포함됩니다(경기도 51,524곳). 실제 사업 단위 또는 사업 가능 지역을 확정한 결과가 아닙니다.
- **MW** — 0.045 kW/㎡를 적용해 면적을 환산한 참고 규모입니다. 실제 설치 가능 용량, 실제 발전량, 실제 계통 접속 가능 용량이 아닙니다.
- **계통** — 한전 공표 자료를 바탕으로 한 읍면동 단위 참고값입니다. 후보 공간 자체의 접속 가능 용량을 의미하지 않습니다.
- **기존 태양광** — 위치가 확인된 공개 자료만 표시합니다. 표시되지 않는 시설이 존재할 수 있습니다.
- **위성** — 배경 위성영상은 분석에 사용한 원자료의 기준 시점과 다를 수 있으며, 현황 확인을 위한 참고자료입니다.
- **규제** — 이 화면에 발행되지 않은 용도지역·주요 규제 레이어는 현재 자문 화면에서 직접 검토할 수 없습니다.

## 시작하기

1. **의견 내보내기** 탭에서 담당자가 알려 드린 **자문자 코드**를 적어 주세요. 성함·소속은 적지 않습니다. 한 브라우저에서 여러 분이 차례로 작성하실 때는 "새 자문 시작"을 누르시면 이전 응답과 섞이지 않습니다.
2. **① 경기도 데이터·후보 결과 확인** — 아래 검토 사례의 "지도에서 보기"를 누르고, 배경을 "위성"으로 두고 근거 레이어를 켜고 끄며 보신 뒤 A1–A5에 답해 주세요.
3. **② 데이터 신뢰성·보완 검토** — B1–B9에 답해 주세요. 탭 맨 위 "사용한 자료의 출처와 시점" 표에서 자료별 제공기관·받은 날·자료 기준 시점을 보실 수 있습니다.
4. **③ 화면 사용성·활용성** — 지역·지번 검색을 해 보시고 C1–C7에 답해 주세요.
5. "자료·산출 설명" 탭은 화면의 값이 어떻게 만들어졌는지 설명하는 참고 자료입니다(평가 대상 아님).
6. **의견 내보내기** 탭에서 D(종합 의견)를 적고, JSON 또는 CSV로 내려받아 담당자에게 보내 주세요. (자문자 배경은 같은 탭의 접이식 칸에 선택으로 적으실 수 있습니다.)

## 드리는 질문

**A. 데이터·후보 결과 확인** (① 탭)
- A1. 위치·경계 현실성 — 이 후보의 위치와 경계를 실제 현황과 비교했을 때 명백히 맞지 않는 부분이 있습니까? (사례별)
- A2. 후보 내부 현황 — 후보 공간 안에 실제로는 농지가 아닌 것으로 보이는 영역(건물·도로·하천·산림 등)이 섞여 있습니까? (사례별)
- A3. 데이터 예외 — 도형 면적과 장부 면적이 크게 다른 사례에서 실제 현황과 비교하여 추가 확인이 필요한 부분이 있습니까?
- A4. 후보이지만 제외가 필요해 보이는 곳 — 실제 검토에서는 제외하는 것이 맞다고 생각되는 후보가 있습니까? ("있음"이면 후보 번호와 이유)
- A5. 현장 누락 가능성 — 실제로는 후보로 검토해 볼 만한데 화면에 후보 공간이 없는 곳이 있다면 적어 주십시오.

**B. 데이터 신뢰성·보완 검토** (② 탭)
- B1. 전반적인 신뢰성 — 후보 공간이 실제 경기도 농지 현황을 대체로 잘 반영한다고 보십니까?
- B2. 후보 생성에 사용된 자료의 신뢰성 — 농지 관련 자료, 소유·토지 자료, 농업진흥지역 경계 자료, 경사 자료, 법정 제외조건 자료, 행정경계 자료를 각각 평가해 주십시오.
- B3. 데이터 정의·분류 — 이름이나 분류의 의미가 실제 행정·현장 용어와 다르게 해석될 가능성이 있는 항목이 있습니까?
- B4. 가장 신뢰가 걱정되는 자료는 무엇입니까? (여러 개)
- B5. 최신성 — 가장 먼저 갱신할 필요가 있는 자료는 무엇입니까? (여러 개 + 이유)
- B6. 완전성 — 현재 자료에 포함되지 않아 후보 결과에서 누락을 만들 수 있는 정보가 있습니까?
- B7. 기존 태양광 자료 — 현재 확보된 기존 태양광 시설 자료가 실제 현황을 파악하기에 어느 정도 충분합니까?
- B8. 추가로 필요한 공간자료는 무엇입니까? (여러 개)
- B9. 현장과 다른 결과 — 잘 아시는 지역에서 실제 현황과 다르게 보이는 후보 결과가 있다면 후보 번호와 이유를 적어 주십시오.

**C. 화면 사용성·활용성** (③ 탭)
- C1. 자신이 잘 아는 시군·읍면동 찾기 (성공 / 헷갈림 / 실패)
- C2. 후보 하나 찾기와 왜 후보인지 이해하기 (성공 / 헷갈림 / 실패)
- C3. 지번·PNU 검색 (성공 / 헷갈림 / 실패)
- C4. 10 / 20 / 50MW 표시는 무엇을 의미한다고 이해하셨습니까?
- C5. 내부 검토에 필요한 정보 — 현재 화면을 내부 검토에 사용하려면 무엇이 추가되어야 합니까?
- C6. 외부 공개 시 주의할 정보 — 오해·민감성 또는 악용 가능성 때문에 제한해야 할 정보가 있다면 무엇입니까?
- C7. 추가 기능·자료 — 실제 업무에 사용한다면 가장 필요할 기능이나 자료는 무엇입니까?

**D. 종합 의견** (의견 내보내기 탭)
- D1. 실제 경기도 현황과 비교했을 때, 이 연구에서 가장 먼저 다시 확인해야 할 데이터 또는 후보 결과가 있다면 무엇입니까?
- D2. 유지할 부분 · D3. 수정 또는 다시 확인할 부분 · D4. 추가로 필요한 자료 · D5. 추가로 필요한 기능
