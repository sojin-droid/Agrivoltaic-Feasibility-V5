# 자문 대응표 양식 — 경기연구원 라이다 분류 경험 ↔ 우리 위성사진 판독

작성 2026-11-01 · 용도: 비농지 제외 방법 자문(경기연구원) 요청서에 붙이는 표. 우리 칸은 채워 두고, 자문자 칸은 비워 둔다. 자문자는 같은 항목에 자기 경험을 적으면 된다.
쓰는 법: 항목마다 "우리가 한 것 → 우리가 못 정한 것"을 적어 두었으므로, 자문자 칸에는 "귀 기관은 어떻게 했는가 · 다시 한다면 바꿀 것 · 하지 말라고 할 것"을 적어 주시면 된다. 수치는 규모 설명용 최소한만 적었고, 정본이 아닌 예비값은 "검토 진행 중"으로 표시했다.

| 항목 | 우리가 한 것 (위성·항공사진 판독) | 우리가 못 정한 것 | 경기연구원 (라이다 분류) — 귀 기관은 어떻게 하셨습니까 | 다시 한다면 바꾸실 것 / 하지 말라고 하실 것 |

| 1. 판독 목적과 결과의 쓰임 | 지목이 농지인 법인·국공유 필지 중 실제로는 농지가 아닌 땅(도로·제방·산림·묘지·건물·공사장)을 걸러 영농형 태양광 후보에서 뺀다. 결과는 후보 공간 집계와 지도에 반영된다. | 후보 선별 용도에 필요한 최소 정확도를 얼마로 둘지(80·85·90·95 %). | | |

| 4. 전처리 — 계절·그림자·해상도 | 두 사진 중 어느 하나라도 논밭이면 농지로 남겼다. 땅이 바뀐 곳은 촬영일이 최근인 쪽을 따랐다. 겨울 맨땅·그림자가 섞인다. 흐린 타일은 선명도(라플라시안 분산)로 가려내 다른 공급자의 봄(3–5월) 영상으로 다시 받는다(검토 진행 중). | 계절을 고정해야 하는지, 여러 시점을 함께 봐야 하는지. 라이다의 잎 있는 철·없는 철, 점 밀도 차이, 지면·비지면 분류 오류 처리. | | |

## 표 뒤에 붙일 짧은 질문 (자문자 경험을 닫힌 형식으로)

- 위 11개 항목 중 **가장 크게 틀렸던 것** 하나와, 그때 무엇이 틀렸는지 한 줄.
- 위 항목 중 **다시 한다면 먼저 바꿀 것** 하나.
- 우리가 한 것 중 **하지 말라고 하실 것** 하나와 이유 한 줄.
- 우리가 **꼭 보라고 하실 사례·자료·논문** 셋.
- 귀 기관이 **직접 해 보신 범위**(해당 항목 번호에 ○).

## 쓰지 않은 것

모델별 정확도 숫자, 자동 구간 비율, 정답 표본 수, 정본 면적·MW, 지번 목록. 모두 검토 진행 중이거나 자문의 대상이 아니다.
