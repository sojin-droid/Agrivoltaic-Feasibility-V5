# 자문자 안내 — 재생에너지지구 내에 영농형 태양광 클러스터 위치 연구 (경기연구원 · 데이터 신뢰성·비농지 제외 방법)

화면: https://sojin-droid.github.io/agrivoltaic-advisory-gg/advisory.html

**이 화면은 연구 결과를 최종 확정하기 위한 화면이 아니라, 연구에 쓴 자료의 신뢰성과 비농지(지목은 농지지만 실제로는 농지가 아닌 땅)를 걸러 낸 방법을 전문가께 검토받기 위한 자문용 화면입니다.** 로그인·설치가 필요 없고, 일반 브라우저로 링크를 열면 됩니다.

- 최종 사업 가능성, 법적 인허가 가능성, 실제 계통 접속 가능 여부를 판단하는 화면이 아닙니다.
- 판단하기 어려운 항목은 "판단 어려움"으로 답하시거나 비워 두셔도 됩니다.
- 의견은 서버로 자동 전송되지 않고 지금 쓰시는 브라우저에만 저장됩니다.

## 탭 구성

1. **데이터 신뢰성·보완 검토** — 연구에 쓴 자료의 출처·받은 날·기준 시점 표와 질문 1(추가로 반영하면 좋을 자료), 선택 질문(정확하지 않거나 오래되어 보이는 자료). 아래쪽에서 자문자 코드를 적고 의견을 파일로 내려받습니다.
2. **비농지 제외 방법** — 자동 제외(도로 중심선·건물 외곽선·폭 10m 미만 띠)와 위성사진 육안 검토로 비농지를 뺀 방법, 유형별 제외 사례, 다시 보니 농지였던 곳(오판 정정 6곳), 질문 11가지. 7–11번은 데이터 신뢰성·영상 전처리 — 연구원에서 라이다 영상을 다루실 때 거치신 과정을 여쭙는 질문입니다.

## 자료를 읽을 때 주의할 점

- **분석 조건** — 영농형태양광 특별법 시행 후, 농업진흥구역에 영농형 태양광을 설치할 수 있게 되는 경우(농업보호구역 제외) · 법인·국공유 농지입니다.
- **후보 공간** — 분석 조건을 통과한 필지를 21m 이내로 이어 묶은 검토 단위입니다(경기도 32,607곳). 실제 사업 단위가 아닙니다.
- **MW** — 0.045 kW/㎡를 적용해 면적을 환산한 참고 규모입니다(1MW = 22,222㎡). 실제 설치·발전·접속 가능 용량이 아닙니다.
- **위성사진** — 비농지 판독에 쓴 Esri·V-World 사진은 촬영 시점이 후보마다 다르며, 자료의 기준 시점과 다를 수 있습니다.
- 비농지 제외 수치는 검토가 진행 중인 값입니다.

## 의견 보내 주시는 방법

- **데이터 신뢰성·보완 검토 탭** — 다 적으신 뒤 탭 아래쪽 "의견 저장·내려받기"에서 JSON 또는 CSV 파일로 내려받아 담당자에게 보내 주십시오. 파일 이름에는 자문자 코드와 날짜가 자동으로 붙습니다.
- **비농지 제외 방법 탭** — 질문 1–11에 대한 의견은 메일로 보내 주십시오. 시간이 짧으시면 1–3번과 7번을 먼저 봐 주십시오.
