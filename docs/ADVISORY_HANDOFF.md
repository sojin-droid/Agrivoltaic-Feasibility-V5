## 4. 21m의 의미

후보 공간 = 판정을 통과한 필지 중 21m 이내로 이어진 필지를 묶은 **최소 공간 분석 단위**입니다. 실제 사업 단위(최종 클러스터)의 정의는 정해지지 않았습니다.

## 5. 10/20/50MW의 의미

면적 × 0.045 kW/㎡ 로 환산한 **참고 규모**입니다(각각 약 0.22 / 0.44 / 1.11 km² 이상). 실제 설치 가능 용량이나 계통 접속 가능 용량이 아닙니다.

## 6. 계통 데이터의 의미

후보가 있는 읍면동의 분산전원 잔여 연계가능용량(한전 공표, 조회 2026-08-19)에서 가져온 **읍면동 단위 참고값**입니다. 같은 읍면동 후보는 같은 값을 가집니다. 개별 사업의 실제 접속 가능성이나 접속 용량을 보장하지 않습니다.

## 7. 기존 시설 데이터의 의미

확보한 공개 자료(발전설비 공개 자료 · 발전사업 허가 자료, 수집 2026-09-21) 중 위치가 검증된 점만 보여 줍니다. 전국 전수조사가 아닙니다. **0곳은 시설이 없다는 뜻이 아닙니다.** 기존 시설 × 21m 후보 공간의 정본 중첩은 **계산되지 않았습니다(NOT COMPUTED)** — 화면의 "후보 안 0곳"은 표시용 확인 결과입니다.
