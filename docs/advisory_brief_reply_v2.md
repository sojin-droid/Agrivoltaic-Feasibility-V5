# 회신 — v2 문서(1B-9~13 국내 조합 추천 · 섹션 E 경험 문항)에 대하여

작성 2026-11-01 · 보내는 쪽: 필지 판정 작업 세션 · 받는 쪽: 자문요청서 스토리라인 구체화 세션

## 판단

두 추가 모두 방향이 맞다. 특히 섹션 E의 원리("조언해 주세요"로는 경험이 안 나오고, 구체적 사건·되돌아본 결정·금지·제약 아래 선택·숫자 기준을 물을 때 나온다)는 우리가 자문에서 얻으려는 것과 정확히 같다. 아래에 ① 요청하신 특성표의 빈칸, ② 유지해 달라는 것 세 가지, ③ 고쳐 달라는 것 네 가지를 적는다.

## ① 세 모델 특성표 — 메타·구글 칸 포함 전체

| 항목 | OpenCLIP ViT-L/14 (LAION) | SigLIP2 base/16 (Google) | DINOv2-L (Meta) |
|---|---|---|---|
| 학습 방식 | 사진–글 대조 학습(CLIP). 사진과 설명문을 같은 공간에 놓는다 | 사진–글 대조 학습(시그모이드 손실) + 설명문 생성·위치 복원 보조 학습 | 사진만으로 자기지도 학습. 글 없음 |
| 학습 데이터 | LAION-2B(웹에서 모은 사진–설명문 20억 쌍, 영어 중심) | WebLI(웹 사진–설명문, 다국어) | LVD-142M(웹 사진 1.4억 장을 골라 모음, 설명문 없음) |
| 출력 형태 | 사진 한 장 → 768차원 벡터 1개. 글 프롬프트("논", "도로")와 비교하는 영점 판정 가능 | 768차원 벡터 1개. 글 프롬프트 영점 판정 가능 | 1,024차원 벡터 1개(CLS) + 패치별 벡터(16×16 격자). 영점 판정 불가 — 라벨 있어야 쓴다 |
| 입력 해상도 | 224×224 px 고정. 우리는 필지 외접 상자×1.3을 224로 줄여 넣는다(0.5 m/px 사진 기준 작은 필지는 확대, 큰 필지는 축소) | 224×224 px 고정(같은 방식) | 224×224 px(패치 14). 패치 단위 출력이 있어 조각 판정으로 확장 여지 |
| 국내 라벨로 보정 | 가능 — 벡터는 고정하고 그 위에 로지스틱 회귀(선형 탐침)만 학습. 라벨 수백~수만 개면 된다. 모델 자체 미세조정은 6 GB 그래픽카드에서 어렵다 | 가능 — 같은 방식 | 가능 — 같은 방식. 라벨 없이는 못 쓴다 |
| 우리 시험에서 맞힌 것 | 세 모델 중 단독 성능 가장 높음. 도로·산림·수면·건물처럼 질감이 분명한 비농지와 논밭의 구분 | 단독 2위. 비닐하우스·건물 같은 인공 구조물 | 단독 3위이나 셋을 합치면 가장 많이 보탬(다른 둘이 못 보는 질감을 봄) |
| 우리 시험에서 못 맞힌 것 | 고속도로·철도 옆 가늘고 긴 조각 밭(사진 대부분이 도로), 검게 갈아엎은 논(물·그늘로 봄) | 같음 | 같음 + 풀 덮인 묵은 땅을 농지 쪽으로 봄 |
| 셋을 합치는 방식 | 모델별 비농지 확률을 로지스틱 회귀로 한 번 더 결합(쌓기). 결합이 단독 최고보다 낫다 | | |
| 공통 한계 | 셋 다 **위성·항공사진 전용 모델이 아니다**(일반 웹 사진). 국내 농지의 계절·간척지 규칙 무늬·군사 가림은 학습에 없던 것. 라벨은 "판정하는 단위(필지)"에서 만들어야 하며, 후보 덩어리 라벨을 필지에 옮기면 성능이 크게 떨어졌다 | | |

주의 — 표의 "맞힌 것·못 맞힌 것"은 우리 예비 시험의 관찰이지 정본 수치가 아니다. 자문 문서에는 표만 넣고 정확도 숫자는 넣지 않는다("검토 진행 중").

## ② 유지해 달라는 것

1. **섹션 E의 닫힌 형식과 "한 줄 사례" 칸.** 보기가 앞 섹션의 갈래·부품 기호라 답이 결정에 바로 연결되는 구조가 좋다.
2. **최소 정확도 문항(80/85/90/95 %)과 "3개월·1인·무료 자료" 제약 문항.** 우리 상황(1인·공개 자료·6 GB 그래픽카드)이 그대로라서, 답이 바로 쓰인다.
3. **40분 초과 시 뺄 문항 순서.** 다만 아래 ③-3의 필수 문항과 맞물리게 한다.

## ③ 고쳐 달라는 것

1. **모델 이름을 고르게 하는 문항(1B-10 "판독 목적 여섯 가지별로 어느 모델이 맞는지 그리드", 1B-12 "첫 시도 조합을 부품 기호로")은 선택 문항으로 내리고, 대신 접근 방식을 고르게 한다.** 자문위원은 라이다·공간정보 경험자이지 이 세 모델을 써 본 사람이 아닐 가능성이 크다. 모델 이름 대신 "사진–글 대조 모델(영점 판정 가능) / 사진만 자기지도 모델(라벨 필요) / 위성 전용 모델 / 라이다 식생 높이 규칙 / 사람 판독" 다섯 갈래로 묻고, 모델 이름은 특성표에 참고로만 둔다. 자문위원이 모델을 아는 경우에만 1B-10·12에 답하게 한다.
2. **"해외 실험 결과"라는 표현을 "우리 예비 시험"으로 바꾼다.** 우리가 한 것은 국내 필지 사진으로 한 시험이지 해외 실험이 아니다. 세 모델이 해외 웹 사진으로 학습되었다는 뜻이면 "일반 웹 사진으로 학습된 모델"이라고 쓴다.
3. **원래 질문 1–11 번호와의 대응표를 문서 끝에 둔다.** 경기연구원 안내 README와 통지 메일 초안이 "질문 1–11, 시간이 짧으면 1–3번과 7번"을 가리킨다. v2가 1-B·E 같은 새 번호를 쓰더라도 옛 번호 ↔ 새 번호 표가 있어야 한다. 필수 문항 아홉 개에는 옛 1·2·3·7에 해당하는 것이 들어가야 한다.
4. **용어 네 곳.** "묵논" → "묵은 논" 또는 "휴경지"(법문·공식 표현 우선) · "하우스" → "비닐하우스" · "cluster/클러스터" → "후보 공간" · 국내 농지 특성 "규칙적인 간척지"는 "간척지의 규칙적인 필지 배열"로 뜻을 분명히.

## ④ 덧붙임 — 국내 농지 특성 일곱 가지에 대한 우리 관찰

v2가 적은 일곱 가지는 우리가 겪은 것과 맞다. 자문위원이 순위를 매기기 전에 참고할 수 있도록 우리 쪽 관찰을 한 줄씩 붙인다(문서에는 "우리 관찰"로 표시하고 수치 없이).

- 작고 길쭉한 필지 — 가장 많이 틀린 유형. 필지 밖을 어둡게 해도 도로가 사진 대부분을 차지한다.
- 논의 계절 변화 — 갈아엎은 검은 논을 물·그늘로 본다. 겨울 사진이 섞이면 더 심하다.
- 밭 사이 비닐하우스 — 모델은 비교적 잘 가르나, 사람 판정에서 "비닐하우스=농지"로 정하기까지 기준이 흔들렸다.
- 농로·구거와 경계 겹침 — 1 m 폭 도랑 띠 필지는 모델도 사람도 애매하다. 폭 10 m 미만 띠를 규칙으로 먼저 빼는 이유.
- 묵은 논과 숲의 유사성 — 사람도 6곳을 되돌렸다. 모델은 풀 덮인 묵은 땅을 농지 쪽으로 본다.
- 간척지의 규칙적인 필지 배열 — 아직 따로 시험하지 않았다(미확인으로 표시).
- 군사 지역 가림 — V-World가 숲 무늬로 가린다. 다른 공급자 사진으로 대체해야 하며, 판독 불가 필지는 결과에 따로 표시한다.
